## Getting Started
1. Need ChatGPT Pro or Business Premium.
2. Download the zip.
3. Extract on Windows 10/11.
4. Open ChatGPT desktop / web / mobile and start a Dot.
5. Notes in `files/notes/`.

## FAQ

**Public API?**
No. Astra is on API / OpenRouter / Bedrock. Dots is a product, not an endpoint.

**Free plan?**
No. Pro / Business Premium. First Dot included.

**Where does it run?**
OpenAI cloud VM. Not a local daemon.

## Requirements
Windows 10/11. ChatGPT Pro or Business Premium. Internet.
